# Вопросы к защите

**Что моделируется?** Физический маятник: графитовый стержень 41,7 см и
латунный груз 28 x 28 x 15 мм на нижнем конце, ось через верхний конец
стержня. Движение в одной плоскости, неизвестная - угол θ от вертикали.

**Откуда массы?** Обе считаются по плотности и объёму: стержень
m = ρπR²L = 8,38 г (графит 1,6 г/см³), груз m = ρ·w·h·s = 99,96 г
(латунь 8,5 г/см³). В коде это свойства `rod_mass_kg` и `bob_mass_kg`.

**Как считается момент инерции?** Стержень режем на тонкие диски:
dI = (R²/4 + x²)dm, интеграл по длине даёт m(L²/3 + R²/4). Груз: момент
относительно центра m(w² + h²)/12 плюс m·a² по теореме Штейнера,
a = L - h/2. Сумма I = 1,673·10⁻² кг·м², d = 38,8 см. В тестах проверено
прямым интегрированием ∫ρr²dV (`tplquad`).

**Какое уравнение решаем?** Уравнение моментов Iθ'' = -mgd·sinθ - bθ'.
Для solve_ivp: θ' = ω, ω' = -(mgd·sinθ + bω)/I и Q' = bω² - теплота трения.
Метод DOP853, rtol = 10⁻¹⁰, atol = 10⁻¹², шаг не больше 0,01 с, сетка 1 мс.

**Как измеряется период?** Моменты перехода θ через ноль снизу вверх
(линейная интерполяция между точками сетки), затем среднее интервалов.

**Почему период зависит от амплитуды?** При малых углах sinθ ≈ θ,
уравнение гармоническое и период T0 = 2π√(I/(mgd)) = 1,26597 с от
амплитуды не зависит (изохронность). На самом деле mgd·sinθ < mgd·θ:
возвращающий момент слабее линейного, маятник возвращается медленнее.
При 60° период больше T0 на 7,3 %, при 150° - на 76 %.

**Откуда эллиптический интеграл и ряд?** Из сохранения энергии
Iω²/2 + mgd(1 - cosθ) = mgd(1 - cosA) получаем ω² = 2ω0²(cosθ - cosA) и
T = 4∫dθ/ω от 0 до A. Замена sin(θ/2) = k·sinφ, k = sin(A/2), даёт
T = (4/ω0)K(k²), где K(m) = ∫dφ/√(1 - m·sin²φ) от 0 до π/2 - полный
эллиптический интеграл первого рода (`scipy.special.ellipk(m)`). Если
разложить подынтегральную функцию по k² и проинтегрировать
(∫sin² = π/4, ∫sin⁴ = 3π/16), то K ≈ (π/2)(1 + k²/4 + 9k⁴/64); с
k² ≈ A²/4 - A⁴/48 получаем T ≈ T0(1 + A²/16 + 11A⁴/3072). Расчёт совпадает
с точной формулой до 6·10⁻¹¹, ряд при 150° занижает период на 9 %.

**Что за погрешность энергии?** Без трения точная энергия
E = Iω²/2 + mgd(1 - cosθ) постоянна. Посчитанная по численному решению
E(t) отличается от E0 только из-за ошибки интегрирования. Мера:
δE = max|E(t) - E0|/E0. Получилось 5·10⁻¹⁵ при 5° и 1·10⁻¹⁴ при 60°.
Двойная точность даёт ошибку порядка 10⁻¹⁶ на операцию, так что это
уровень округления.

**Почему при 5° погрешность не больше, чем при 60°?** Потенциальная
энергия считается как U = 2mgd·sin²(θ/2), а не mgd(1 - cosθ). При малом
угле 1 - cosθ — разность близких чисел (при 5° это 0,0038), ошибка
округления в ней относительно в сотни раз больше. С формулой через 1 - cosθ
было 2,1·10⁻¹⁴ при 5°, с sin² стало 5,1·10⁻¹⁵. С трением E убывает, поэтому проверяем баланс:
max|E + Q - E0|/E0 = 1,8·10⁻¹⁴, где Q = ∫bω²dt.

**Зачем трение и как оно сравнивается с теорией?** Чтобы проверить
затухающие колебания из задания. Трение вязкое, момент -bθ'. Умножив
уравнение на ω, получаем dE/dt = -bω², энергия переходит в теплоту.
При малых углах θ = e^(λt) даёт λ = -β ± iωd, β = b/(2I), то есть
θ ≈ A·e^(-βt)·cos(ωd·t). b подобрано так, чтобы амплитуда падала вдвое за
30 с: β = ln2/30 = 0,0231 с⁻¹, b = 2Iβ = 7,7·10⁻⁴ Н·м·с, β/ω0 ≈ 0,005.
β по наклону ln θmax(t) совпадает с теорией с точностью 0,03 %, энергия
идёт по E0·e^(-2βt), период Td = 2π/√(ω0² - β²) отличается от T0 на 10⁻⁵.

**Как запускать?** `python -m physical_pendulum`, графики и
`parameters.json` сохраняются в `results/<дата_время>/`. Без дисплея:
`MPLBACKEND=Agg python -m physical_pendulum`. Аргументов командной строки
нет, все параметры меняются в `physical_pendulum/config.py`.
