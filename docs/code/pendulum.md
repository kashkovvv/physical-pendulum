# `physical_pendulum/pendulum.py`

## Назначение

Модуль численно решает уравнение колебаний физического маятника

$$
I\ddot\theta = -mgd\sin\theta - b\dot\theta,
$$

считает энергию и теплоту трения, измеряет период и коэффициент затухания по
готовому решению и выполняет все расчёты задания. Параметры тела и настройки
интегрирования берутся из `config.py`, вывод формул приведён в отчёте
`report/report.pdf`.

## Используемые средства Python

`@dataclass(frozen=True)` автоматически создаёт конструктор и запрещает
переназначать поля готового результата. Это защищает рассчитанные значения от
случайного изменения. Неизменяемость контейнера не делает вложенные массивы
NumPy неизменяемыми.

`@property` превращает метод без аргументов в вычисляемое поле: значение
`result.period_s` пересчитывается из массивов при каждом обращении и не
хранится отдельно.

`NDArray[np.float64]` обозначает массив NumPy с вещественными элементами
двойной точности. Аннотация нужна для статической проверки `mypy`.

## `PendulumResult`

Неизменяемая история одного расчёта:

| Поле | Смысл | Единица |
|---|---|---:|
| `time_s` | моменты времени равномерной сетки вывода | с |
| `angle_rad` | угол отклонения от вертикали $\theta$ | рад |
| `angular_velocity_rad_s` | угловая скорость $\omega = \dot\theta$ | рад/с |
| `energy_j` | механическая энергия $E = K + U$ | Дж |
| `dissipated_energy_j` | теплота трения $Q$, выделившаяся с начала расчёта | Дж |

Вычисляемые свойства:

| Свойство | Смысл |
|---|---|
| `amplitude_rad` | начальное отклонение $\theta(0) = A$ |
| `energy_relative_error` | $\delta_E = \max_t \lvert E(t) - E_0\rvert / E_0$, проверка сохранения энергии без трения |
| `balance_relative_error` | $\max_t \lvert E(t) + Q(t) - E_0\rvert / E_0$, проверка баланса с трением |
| `period_s` | средний период, измеренный функцией `measure_period()` |

## `PendulumModel`

Класс хранит проверенные объекты `PendulumParameters` и
`IntegrationParameters`. Метод

```python
model.simulate(amplitude_rad, duration_s, damped=False)
```

решает уравнение движения при $\theta(0) = A$, $\omega(0) = 0$ и возвращает
`PendulumResult`. Флаг `damped` включает вязкое трение с коэффициентом
`pendulum.damping_n_m_s`; без него $b = 0$.

Внутреннее состояние содержит угол, угловую скорость и теплоту, именно в
таком порядке. Вложенная функция `derivatives()` возвращает их производные:

$$
\dot\theta = \omega, \qquad
\dot\omega = -\frac{mgd\sin\theta + b\omega}{I}, \qquad
\dot Q = b\omega^2.
$$

Третье уравнение нужно только для проверки баланса $E + Q = E_0$: теплота
интегрируется вместе с движением с той же точностью. Функция получает время
и массив состояния, как требует `solve_ivp`; время в уравнения не входит,
поэтому параметр назван `_time_s`. Замыкание даёт ей доступ к $I$, $mgd$ и
$b$ без глобальных переменных.

`scipy.integrate.solve_ivp` численно решает начальную задачу методом
`DOP853` — явным методом Рунге — Кутты восьмого порядка с автоматическим
выбором шага. Шаг уменьшается, если оценка локальной ошибки больше допуска
`rtol * abs(y) + atol`, и увеличивается, если меньше. `max_step` ограничивает
шаг сверху, чтобы решатель не перешагивал через колебания. Параметр `t_eval`
задаёт равномерную сетку вывода с шагом `output_step_s`: решатель сам
выбирает точки интегрирования, а значения в точках сетки получает
интерполяцией.

После решения энергия считается по угловой скорости и углу:

$$
E = \frac{I\omega^2}{2} + 2mgd\sin^2\frac{\theta}{2}.
$$

Потенциальная энергия $mgd(1 - \cos\theta)$ записана через квадрат синуса
половинного угла. При малом угле $1 - \cos\theta$ — разность близких чисел, и
ошибка округления в ней относительно велика; во второй записи вычитания нет.

Алгоритм `simulate()`:

1. Проверить, что амплитуда лежит в интервале $(0, \pi)$, а длительность
   положительна, иначе вызвать `ValueError`.
2. Вычислить $I$, $mgd$ и $b$.
3. Построить сетку вывода `np.linspace` с шагом `output_step_s`.
4. Выполнить `solve_ivp`; если `solution.success` ложно, вызвать
   `RuntimeError` с сообщением решателя.
5. Получить из `solution.y` угол, скорость и теплоту, вычислить энергию и
   вернуть `PendulumResult`.

## Обработка решения

`upward_crossings_s(time_s, angle_rad)` находит моменты, когда угол
переходит через ноль снизу вверх. Выражение
`(angle_rad[:-1] < 0) & (angle_rad[1:] >= 0)` сравнивает каждую точку со
следующей сразу для всего массива, `np.nonzero` возвращает номера таких пар.
Момент перехода внутри шага находится линейной интерполяцией: прямая через
две соседние точки пересекает ноль при

$$
t = t_j - \theta_j \frac{t_{j+1} - t_j}{\theta_{j+1} - \theta_j}.
$$

`measure_period(time_s, angle_rad)` возвращает среднее расстояние между
соседними переходами: соседние переходы в одну сторону разделены ровно одним
периодом. Если переходов меньше двух, расчёт короче периода и вызывается
`ValueError`.

`find_peaks(time_s, angle_rad)` возвращает времена и значения положительных
максимумов угла — точек сетки, которые больше левого соседа и не меньше
правого.

`fit_decay_rate_1_s(result)` находит коэффициент затухания $\beta$ по
максимумам. Если $\theta_{\max} = Ae^{-\beta t}$, то
$\ln\theta_{\max} = \ln A - \beta t$ — прямая. `np.polyfit(..., 1)` проводит
через точки $(t, \ln\theta_{\max})$ прямую методом наименьших квадратов и
возвращает её наклон и свободный член; наклон, взятый с обратным знаком, и
есть $\beta$.

## Все расчёты задания

`ExperimentResults` — неизменяемый контейнер с результатами:

| Поле | Смысл |
|---|---|
| `pendulum` | параметры маятника, для которых выполнен расчёт |
| `small` | свободные колебания с малой амплитудой `SMALL_AMPLITUDE_DEG` |
| `large` | свободные колебания с большой амплитудой `LARGE_AMPLITUDE_DEG` |
| `period_amplitudes_deg` | амплитуды для зависимости периода, град |
| `periods_s` | измеренные периоды для этих амплитуд, с |
| `damped` | затухающие колебания с амплитудой `DAMPED_AMPLITUDE_DEG` |

`run_experiments(pendulum, integration)` создаёт одну модель и выполняет на
ней все расчёты. Амплитуды и длительности берутся из констант `config.py`;
градусы переводятся в радианы функцией `math.radians`. Для зависимости
периода от амплитуды уравнение решается заново для каждой амплитуды из
`PERIOD_AMPLITUDES_DEG`, и от каждого решения сохраняется только период.
