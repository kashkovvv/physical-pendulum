# `physical_pendulum/theory.py`

## Назначение

Модуль содержит теоретические формулы, с которыми сравнивается численное
решение. Все функции принимают проверенный объект `PendulumParameters` и
только вычисляют значения: состояния нет, входные данные не меняются. Вывод
формул приведён в отчёте `report/report.pdf`.

Частота малых колебаний $\omega_0 = \sqrt{mgd/I}$ и коэффициент затухания
$\beta = \ln 2 / t_{1/2}$ берутся из свойств `natural_frequency_rad_s` и
`decay_rate_1_s` объекта параметров.

## Используемые средства Python

Функции, которые работают с массивами времени, принимают и возвращают
`NDArray[np.float64]`. Операции `np.cos` и `np.exp` применяются сразу ко
всем элементам массива, поэтому теоретическая кривая для всей сетки времени
получается одним вызовом без цикла.

Функции, которые возвращают одно число, используют модуль `math`, а значение
из SciPy приводится к `float`, чтобы тип результата был обычным числом
Python.

## Период свободных колебаний

| Функция | Формула | Где верна |
|---|---|---|
| `small_angle_period_s(pendulum)` | $T_0 = 2\pi/\omega_0 = 2\pi\sqrt{I/(mgd)}$ | малые углы |
| `series_period_s(pendulum, amplitude_rad)` | $T_0\left(1 + \dfrac{A^2}{16} + \dfrac{11A^4}{3072}\right)$ | умеренные углы |
| `exact_period_s(pendulum, amplitude_rad)` | $\dfrac{4}{\omega_0}K\left(\sin^2\dfrac{A}{2}\right)$ | любая амплитуда $0 < A < \pi$ |

Амплитуда $A$ передаётся в радианах.

`exact_period_s()` использует `scipy.special.ellipk(m)` — полный
эллиптический интеграл первого рода

$$
K(m) = \int_0^{\pi/2}\frac{d\varphi}{\sqrt{1 - m\sin^2\varphi}}.
$$

Функция принимает параметр $m = k^2 = \sin^2(A/2)$, а не сам модуль $k$,
поэтому в код передаётся квадрат синуса. Интеграл не выражается через
элементарные функции, и SciPy считает его численно с машинной точностью.

`series_period_s()` — первые члены разложения точной формулы по степеням
амплитуды. Ряд показывает, как период растёт с амплитудой, но при больших
углах занижает его.

## Свободные колебания при малых углах

`small_angle_angle_rad(pendulum, time_s, amplitude_rad)` возвращает
решение гармонического уравнения $\ddot\theta + \omega_0^2\theta = 0$ при
$\theta(0) = A$, $\dot\theta(0) = 0$:

$$
\theta(t) = A\cos\omega_0 t.
$$

## Затухающие колебания при малых углах

| Функция | Формула | Смысл |
|---|---|---|
| `damped_envelope_rad(pendulum, time_s, amplitude_rad)` | $Ae^{-\beta t}$ | огибающая: амплитуда в момент $t$ |
| `damped_period_s(pendulum)` | $T_d = \dfrac{2\pi}{\sqrt{\omega_0^2 - \beta^2}}$ | период с трением |
| `damped_energy_j(pendulum, time_s, initial_energy_j)` | $E_0e^{-2\beta t}$ | энергия колебаний |

Энергия пропорциональна квадрату амплитуды, поэтому её показатель
экспоненты вдвое больше, чем у амплитуды. `damped_period_s()` требует
$\beta < \omega_0$: при более сильном трении колебаний нет и корень не
определён. В модели $\beta/\omega_0 \approx 0{,}005$, это условие выполнено.
