# М5 «Физический маятник»

Численная модель свободных колебаний лабораторного маятника по геометрии
PASCO ME-9821: массивный цилиндрический стержень и закреплённый прямоугольный
груз. Практический вопрос: как амплитуда и положение груза влияют на период
и на измерение ускорения свободного падения?

Выполнена только основная часть М5 из «ВШПИ_прог_26-27», стр. 12–13:
расчёт момента инерции по форме, нелинейные колебания без трения,
зависимость периода от амплитуды, сохранение энергии, малое вязкое трение,
сравнение с теорией. Неваляшка, связанные маятники и резонанс не реализуются.
Структура проекта следует подходу М3 [mars-flight](https://github.com/kashkovvv/mars-flight):
Python, NumPy, SciPy, Matplotlib, отдельные параметры, расчёты, графики и тесты.

## Установка

Python 3.11 или новее:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Запуск

```bash
python -m physical_pendulum
```

Программа рассчитывает все эксперименты, печатает итоговые величины, сохраняет
семь графиков PNG, шесть CSV и summary.json в отдельную папку `results/`,
затем открывает графики. Закройте окна, чтобы завершить работу.

Без графического интерфейса:

```bash
python -m physical_pendulum --no-show
python -m physical_pendulum --no-show --output results/my-run
python -m unittest discover -s tests -v
```

Все физические параметры находятся в `physical_pendulum/config.py` и заданы
в СИ. Углы внутри модели задаются в радианах. Исходные паспортные данные
отделены от предположений: положение груза 35 см, идеализация его формы и
время полузатухания 30 с выбраны для расчёта. Трение не выдаётся за измеренное.
Численная точность не означает такую же точность воспроизведения прибора.

## Отчёт и сдача

- `report/report.pdf` — готовый отчёт с формулами, графиками, таблицами и источниками.
- `report/data/` — исходные расчётные данные отчёта, параметры и версии библиотек.
- `report/figures/` — графики в хорошем разрешении.
- `report/test-results.txt` — результат запуска автоматических тестов при сборке.
- `submission/physical-pendulum-m5.zip` — архив с кодом, тестами и PDF.
- `docs/model.md` — вывод уравнений, метод решения и ограничения.
- `docs/experiments.md` — сценарии и критерии проверки.
- `docs/sources.md` — происхождение параметров и ссылки.
- `docs/defense.md` — краткая подготовка к защите.

Для воспроизведения отчёта и архива из корня проекта:

```bash
python -m pip install -r requirements-report.txt
python -m report.build_report
python -m report.package
```

Сборка отчёта заново выполняет расчёты. Сборка архива сначала запускает тесты
и прекращается при ошибке. Для кириллицы используются DejaVu Sans из Matplotlib;
системная установка LaTeX не нужна. `requirements-lock.txt` фиксирует версии
среды, в которой был построен приложенный отчёт (Python 3.14); для другой версии
Python используйте обычные requirements-файлы.
