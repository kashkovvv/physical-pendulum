# М5 «Физический маятник»

Авторы: Кашков Сергей, Богославский Родион.

Модель физического маятника, который качается в вертикальной плоскости.
Тело — графитовый стержень (длина 41,7 см, диаметр 4 мм) и латунный груз
28 x 28 x 15 мм на нижнем конце; ось проходит через верхний конец стержня.
Массы считаются по плотностям: стержень 8,4 г (графит 1,6 г/см³), груз
99,96 г (латунь 8,5 г/см³). Уравнение колебаний
Iθ'' = -mgd·sinθ - bθ' решается численно (`scipy.integrate.solve_ivp`).

Выполнена только основная часть задания:

- по форме тела рассчитан момент инерции (стержень + груз, теорема Штейнера);
- получены свободные колебания без трения;
- изучена зависимость периода от амплитуды;
- проверено сохранение энергии;
- добавлено малое вязкое трение, изучены затухающие колебания;
- все результаты сравниваются с теоретическими формулами.

## Установка

Требуется Python 3.11 или новее. Зависимости: NumPy, SciPy и Matplotlib.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Запуск и проверки

```bash
python -m physical_pendulum
python -m unittest discover -s tests -v
```

Программа выводит основные результаты, сохраняет графики в новую папку
`results/ГГГГ-ММ-ДД_ЧЧ-ММ-СС_микросекунды/` и открывает их на экране.
Без дисплея (например, на сервере) окна не нужны, графики только
сохраняются:

```bash
MPLBACKEND=Agg python -m physical_pendulum
```

В папке запуска находятся:

- `geometry.png` — схема маятника;
- `free.png` — свободные колебания при 5° и 60° и относительная погрешность
  энергии;
- `period.png` — период от амплитуды: расчёт, ряд и точная формула;
- `damped.png` — затухающие колебания, огибающая и энергия;
- `parameters.json` — параметры, с которыми выполнен расчёт.

Тесты сравнивают момент инерции с прямым интегрированием по объёму,
период с теоретическими формулами, проверяют энергию без трения,
баланс «энергия + теплота» и скорость затухания с трением.

## Параметры

Все входные параметры находятся в `physical_pendulum/config.py`: размеры,
плотности графита и латуни, g, время полузатухания амплитуды, амплитуды и
продолжительность расчётов, допуски интегрирования. Расчёты ведутся в СИ,
углы в `config.py` заданы в градусах. Неверные значения (не положительные
или груз длиннее стержня) отклоняются с `ValueError`.

## Отчёт

PDF-отчёт с выводом формул, графиками и сравнением с теорией:
`report/report.pdf`. Он собирается скриптом `report/build_report.py`, который
заново выполняет все расчёты и строит графики. Для сборки нужна ещё
библиотека ReportLab:

```bash
python -m pip install -r requirements-report.txt
python -m report.build_report
```
