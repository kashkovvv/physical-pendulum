# Эксперименты и проверки

Все сценарии запускаются командой `python -m physical_pendulum --no-show`.
Результаты отчёта строятся теми же функциями, не переписываются вручную.

1. Без трения: 60°, нулевая начальная скорость, длительность 20T₀.
   Угол и фазовая траектория, кинетическая/потенциальная/полная энергии,
   точное нелинейное решение через функцию Якоби. Целевая относительная
   ошибка энергии <1e-8, абсолютная ошибка угла <2e-7 рад.
2. Период от амплитуды: 1°, 5°, 15°, 30°, 60°, 90°, 120°, 150°, 170°;
   по 6 точных периодов для каждого опыта. Сравнение событий численного
   решения с эллиптическим интегралом. Порог ошибки периода <2e-8.
3. Слабое трение: начальные углы 5° и 60°, длительность 60 с;
   время полузатухания 30 с. Сравнение 5° с линейной теорией, оценка β
   по максимумам, E+Q=E₀. При 60° — изменение локального периода.
   Для строгого теста линейного предела отдельно используется 1°.
4. Практический опыт: перестановка груза на 15, 25, 35, 40 см при 5°.
   Момент инерции и центр масс пересчитываются для каждой позиции.
5. Определение g: подставить измеренный период в формулу малых углов
   g_est=4π²I/(S T²) и оценить систематическую ошибку при больших амплитудах.
6. Сходимость: 120°, 20T(120°), rtol от 1e-4 до 1e-10, atol=rtol/100,
   max_step=T₀. Ошибка угла относительно точного решения должна снижаться.

Автотесты также проверяют независимое интегрирование момента инерции,
равновесие, отрицательный начальный угол, ненулевую начальную скорость,
инвариантность периода при масштабировании масс, ограничения параметров.
Команда: `python -m unittest discover -s tests -v`.

## Как повторить физически

Установить прибор на жёсткой опоре, измерить положение центра груза от оси,
зарегистрировать угол датчиком. Для определения T измерить время нескольких
полных колебаний при 5°; определить I и S по геометрии и вычислить g.
Сопоставить результат с местным g с учётом погрешностей размеров и времени.
Для трения снять максимумы A_n, аппроксимировать ln A_n=C−βt_n,
вычислить b=2Iβ; проверить линейность графика. Если график не прямой,
одного вязкого члена недостаточно. Экспериментальные измерения в работе
не выполнялись: приведены вычислительные испытания реалистичной модели.
